# Références d'origine

Ces données servent à comparer la réécriture au Cappella Windows d'origine.

- windows-menu-inventory.json : inventaire des menus extraits du binaire d'origine.
- detx-structure-audit.json : structure anonymisée du fichier DetX fourni au début du projet.

Ce sont des relevés historiques, pas l'état actuel des fonctions ou des tests.
Le rapport DetX ne contient pas le texte des dialogues. Les limites actuelles sont
décrites dans [Architecture](../ARCHITECTURE.md) et [Windows](../WINDOWS.md).
